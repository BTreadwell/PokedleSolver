One night I was playing [Pokedle](https://pokedle.com/) and realized that it would be more informative to make a guess that I knew was wrong! I got more information from a query that I knew was wrong than I could've gotten from a query that was possibly correct.

This was unintuitive to me at the time and it made me question how you could determine the optimal guess to make at each step in a game of Pokedle. This led me down a Game Theory rabbit hole centered around the concept of Minimax'ing: the idea that the best guess in a game like Pokedle is the guess that minimizes the maximum cost of a wrong guess.
